\section{Bashcrawl}

Bashcrawl is text based adventure game that you can play through your terminal that is akin to the earliest computer games, such as Dungeon. It is a short game where you will explore different rooms (directories) and interact with files and programs to gain treasure, fight monsters, and become more proficient using different commands in Linux.

%The repository can be found here: \href{https://gitlab.com/slackermedia/bashcrawl}{https://gitlab.com/slackermedia/bashcrawl}

As adventure games developed many text based adventure games later developed graphics and also provided a score or rating to the player for what they accomplished during their adventure. For this assignment you'll earn points based on completing different objects. There are 7 total objectives for you to complete, and you must complete 5 objectives to earn the maximum of 10 points for this activity.

To begin, run the following command after connecting to DEAC:

\vspace{0.2in}

\begin{boxedminipage}[]{0.93\textwidth}
\begin{verbatim}
source /deac/csc/classes/csc191/software/bashcrawl/start
\end{verbatim}
\end{boxedminipage}
\newline

If you ever want to reset the adventure you can run the above command again and start a new game.
